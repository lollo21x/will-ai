Le risposte sono generate sul tuo dispositivo e possono contenere errori.

Come ti chiami?

Serve solo per salutarti e per farti conoscere all'AI. Resta salvato su questo dispositivo.

Scegli il modello

Il download avviene una sola volta, poi l'AI funziona anche offline. Usa il Wi-Fi.

Porta qui il tuo calendario

L'AI legge un file .ics che scegli tu. Il file viene letto sul dispositivo e non viene mai inviato altrove.

  1. Apri calendar.google.com dal browser (da iPhone usa la versione desktop del sito).
  2. Tocca l'ingranaggio, poi Impostazioni e Importa/Esporta.
  3. Premi Esporta: scarica uno zip con un file .ics per ogni calendario.
  4. Decomprimilo (su iPhone basta toccare lo zip nell'app File) e scegli qui sotto il file del tuo calendario.
  1. Su Mac: nell'app Calendario fai clic destro sul calendario, poi Esporta… e salva il file .ics.
  2. Su iPhone: apri icloud.com/calendar, tocca l'icona di condivisione accanto al calendario e attiva Calendario pubblico.
  3. Copia il link, incollalo in Safari sostituendo webcal:// con https://: si scarica il file .ics.
  4. Scegli il file qui sotto, poi puoi disattivare la condivisione pubblica.
  1. Apri outlook.live.com/calendar e vai in Impostazioni, poi Calendario e Calendari condivisi.
  2. Sotto Pubblica un calendario scegli quale calendario e il livello di dettaglio, poi Pubblica.
  3. Copia il link ICS e aprilo nel browser: si scarica il file .ics.
  4. Scegli il file qui sotto.
